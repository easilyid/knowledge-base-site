QFramework 框架（QFramework）

是什么

QFramework 是一套为 Unity 设计的系统设计架构与工具集，由凉鞋（liangxiegame）开源维护。它分为两层：

  • QFramework.cs（~1000 行架构核心）：提供符合 SOLID 原则、支持 DDD/事件驱动/数据驱动/分层/MVC/CQRS/模块化的架构本体
  • QFramework.Toolkits（工具集）：集成 CoreKit / UIKit / ActionKit / ResKit / PackageKit / AudioKit 等全部官方工具

核心模块

模块定位核心能力
CoreKit代码工具单例模式、对象池、事件系统、代码生成基础设施
ResKit资源管理同一 API 加载 AB/Resources/网络/自定义来源；引用计数管理；开发期模拟模式免打包
UIKitUI 管理UI 面板生命周期、层级/栈管理、UIPanel/UIElement 代码生成、异步加载
ActionKit动作序列顺序/并行/条件执行、延时、协程、DOTween/UniRx 集成
AudioKit音频管理背景音乐/人声/音效三种 API、音量控制、默认通过 ResKit 加载
PackageKit包管理QFramework 模块的安装与更新管理
FluentAPI链式扩展大量常用 Unity/C# API 的链式（Fluent）静态扩展方法

核心用法

架构本体：QFramework.cs

QFramework.cs 提供了一套轻量的架构规范（~1000 行），核心概念包括 IOC 容器、命令模式、事件系统、模块化。架构的定位是”不绑定具体业务，可以放在笔记应用里保存”——开发者将它复制到项目中作为架构起点。

ResKit：统一资源加载

ResKit 的核心设计是用同一 API 从多种来源加载资源，并根据项目不同阶段切换模式：

阶段模式行为
开发模拟模式直接从 dataPath 加载，免打 AB 包
测试真实模式打一次 AB 包即可
生产真实模式AssetBundle + 自定义 Res 远程加载

UIKit：UI 快速开发

UIKit 默认使用 ResKit 加载 UI 资源，并提供 UIPanel/UIElement 代码生成工具，自动绑定 GameObject 引用。

ActionKit：动作序列执行

AudioKit：音频管理

微信小游戏适配

QFramework 的 ResKit 底层默认从本地磁盘读取 AB 包，与微信小游戏的远程异步加载要求冲突。以下是实际项目中的适配方案。

核心矛盾

平台加载流程
传统 APP检查更新 → 下载全量资源 → 写入文件系统 → LoadFromFile
微信小游戏AB 文件名带 Hash → UnityWebRequest 按需下载 → 底层自动缓存

解决方案

  1. 自定义 Res 实现远程加载：QFramework 的路径前缀机制（resources://、自定义前缀）可扩展支持网络资源加载，实现为 AOP 切面

  2. 魔改 .bin 文件初始化：.bin 文件记录了 AB 包依赖关系和资源→AB 包名映射，需上传到服务器并在 ResKit 异步初始化时远程下载

  3. Hash 后缀问题：打 AB 包时必须 BuildAssetBundleOptions.AppendHashToAssetBundleName，但 .bin 中的包名默认不含 Hash。方案：遍历 AB 包，将含 Hash 包名存入 txt 文件并上传服务器，加载时匹配拼接 URL

WebGL 内存开销

尽早调用 ab.Unload(false)

相比 APP 常用的 LoadFromFile，WebGL 多了 HTTP→WASM→AB 三次拷贝的开销。必须尽早 Unload，并自行维护 Asset 引用计数管理资源生命周期。

其他注意事项

问题说明
框架魔改标记修改处加 //Update by xxx //修改 //魔改 注释，方便维护
转换工具副作用引入微信小游戏转换工具后只能打 WebGL 的 AB 包，其他平台需临时移除工具
多平台统一加载业务侧向最受限平台看齐——统一用 UnityWebRequest 异步加载，用 Unity 宏做多路测试
审核加载超时CDN 未开启可能导致审核超时被打回；最保守方案：全部资源放 Resources 压入首包

审核可能因网络问题打回

即使技术方案有效，审核方可能因 CDN/网络问题加载超时。最保守的过审方案：放弃 AB 包远程加载，全部资源放 Resources 首包。

常见陷阱

ResKit 与微信小游戏的默认冲突

ResKit 默认从本地磁盘读 AB 包，微信小游戏不支持。使用微信小游戏时必须自定义 Res 实现远程加载。

UIKit/AudioKit 默认依赖 ResKit

如果替换了 ResKit 的加载方式，UIKit 和 AudioKit 的资源加载路径也需要同步调整。可通过各自的 Config.xxxLoaderPool 自定义加载器。
