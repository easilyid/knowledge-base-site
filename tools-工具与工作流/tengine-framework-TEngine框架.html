TEngine 框架（TEngine Framework）

是什么

TEngine 是一套面向 Unity 的全平台热更新游戏框架（v6.0.0），核心卖点是 HybridCLR 原生 C# 热更 + YooAsset 资源管线 + 模块化运行时。适用于中大型商业项目，覆盖从启动流程、资源管理、UI 系统到构建部署的完整链路。

与 ET Framework 侧重服务端多进程不同，TEngine 聚焦客户端全栈——热更、资源、UI、配表一站式解决。与 QFramework 相比，TEngine 更重工程化（CI/CD、加密、CDN 分发），QFramework 更轻量灵活。

四层架构

依赖方向严格向下。HotFix 层通过反射入口 GameApp.Entrance 实现与 Runtime 的控制反转。

Runtime Core

ModuleSystem（静态服务定位器）

框架的骨架。所有运行时模块通过它注册、检索、更新、销毁。

组件职责
_moduleMapsDictionary<Type, Module> — O(1) 模块检索
_updateModulesLinkedList — 按 Priority 排序的帧更新队列
RootModuleMonoBehaviour 入口，驱动 ModuleSystem.Update()
GameModule静态 Facade，缓存常用模块引用（GameModule.Resource 等）

模块生命周期：GetModule<T>() 首次调用 → Activator.CreateInstance → OnInit() → 每帧 Update() → 退出时 Shutdown()。

设计模式

ModuleSystem 本质是 服务定位器模式，配合 GameModule Facade 降低调用侧耦合。与 QFramework 的 IOC 容器相比，TEngine 选择了更简单直接的静态定位。

GameEvent（零 GC 事件总线）

全局发布-订阅系统，支持 int 和 string 两种事件 ID。

零 GC 实现：

  • 使用 int 事件 ID 作为字典 key
  • 泛型 Action<T1..T6> 委托，避免值类型装箱
  • 直接委托调用，无中间分配

重入安全：EventDelegateData 维护三个列表（_listExist / _addList / _deleteList），dispatch 期间的增删操作缓冲到 CheckModify() 后合并。

Source Generator：GameEventSourceGenerator（Roslyn）处理 [EventInterface] 标记的接口，编译期生成 int 常量 + 分发实现 + GameEventHelper.Init() 注册方法。

MemoryPool（纯 C# 对象池）

与 ObjectPoolModule（Module 级，管理 ObjectBase 派生对象，支持锁定/优先级/自动释放）形成两级池化体系。详见 object-pool-对象池。

Procedure 启动流程

TEngine 用 FSM 驱动的 Procedure 链管理从冷启动到业务逻辑的全过程：

每个 Procedure 继承 ProcedureBase，通过 ChangeState<T>() 转移。ProcedureSetting（ScriptableObject）配置可用 Procedure 列表和入口类型名。

控制反转点

ProcedureLoadAssembly 加载 DLL 后，通过反射调用 GameApp.Entrance(object[])。此后控制权交给 HotFix 层——主包代码不再直接调用业务逻辑。

热更新系统（HybridCLR）

阶段操作
编译编译 GameLogic.dll / GameProto.dll
打包复制到 AssemblyTextAssetPath 为 .bytes，可选混淆
运行时ProcedureLoadAssembly 加载 → 反射调用 GameApp.Entrance

GameApp.Entrance 内部流程：

  1. GameEventHelper.Init() — 注册 Source Generator 生成的事件接口
  2. 保存热更程序集列表
  3. 注册销毁回调
  4. StartGameLogic() — 启动业务

UpdateSetting（ScriptableObject）定义哪些 DLL 是热更程序集、哪些是 AOT 元数据程序集。

资源管理（YooAsset 集成）

ResourceModule 封装 YooAsset，通过 ResourceModuleDriver（MonoBehaviour）配置启动参数。

运行模式

模式场景
EditorSimulateMode开发期，免打 AB 包
OfflinePlayMode单机/内置资源
HostPlayModeCDN 热更分发
WebPlayModeWebGL 专用

加载 API

  • 同步：LoadAsset<T>()
  • 异步：LoadAssetAsync<T>() → 返回 UniTask
  • GameObject：LoadGameObjectAsync() — 自动实例化 + 引用计数
  • 推荐搭配 CancellationToken 防泄漏

加密

  • FileOffsetDecryption：字节偏移
  • FileStreamDecryption：XOR 流式解密（BundleStream）

包版本/来源角色
