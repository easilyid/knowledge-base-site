ScriptableObject

是什么

ScriptableObject 是派生自 UnityEngine.Object 的可序列化 Unity 类型。它不像 MonoBehaviour 那样挂在 GameObject 上，而是通常作为项目资产独立存在，用来保存共享数据或编辑器状态。

ScriptableObject 的核心价值：让数据独立于行为，让同一份数据被多个消费者共享。

关键细节

独立于 GameObject

ScriptableObject 资产可以被多个场景对象、Prefab 或其他资产引用。多个对象引用同一个 ScriptableObject 时，读到的是同一份资产数据——这是与 Prefab 实例化（深拷贝）的根本区别。

创建方式

方式场景说明
[CreateAssetMenu]Editor 菜单创建最常用，右键菜单 → Create → Game/Weapon Data
ScriptableObject.CreateInstance<T>()运行时创建纯内存实例，不保存到磁盘
AssetDatabase.CreateAssetEditor 脚本持久化编辑器工具中保存为 .asset 文件
Addressables / AssetDatabase运行时加载从 AssetBundle 或 Addressables 加载

持久化限制

在 standalone Player 运行时，通常只能读取已保存的 ScriptableObject 资产数据。运行时对内存实例的修改不会自动写回磁盘资产文件。

ScriptableObject 不是自动存档系统

它适合保存项目资产数据，不等于玩家运行时存档。Player 中修改内存实例不会自动写回项目资产。存档系统应使用 JSON/Binary 文件 + 持久化路径。

生命周期回调

ScriptableObject 有与 MonoBehaviour 类似但更简化的生命周期：

回调触发时机说明
AwakeCreateInstance 或资产加载时初始化非序列化字段
OnEnable首次加载、Domain Reload 后注册事件、初始化运行时状态
OnDisable卸载前、Domain Reload 前注销事件
OnDestroy资产被销毁时清理外部资源
OnValidateInspector 修改值后校验、联动（Editor only）

ScriptableObject 没有 Update/FixedUpdate

ScriptableObject 不参与 PlayerLoop 系统 的帧循环——它没有 Update、FixedUpdate、LateUpdate 等回调。如果需要每帧逻辑，应由引用它的 MonoBehaviour 驱动。

反模式

共享引用会共享状态

如果多个对象引用同一个 ScriptableObject，并且运行时修改了其中字段，所有引用者看到的都是同一份变化。这在多人测试时尤其容易出问题——“为什么所有敌人血量一起变了？“。需要独立状态的数据不应放在 ScriptableObject 中，或应实现 Copy-on-Write 模式。

大数组不适合 YAML

Unity API 文档建议大数组或大数据考虑 PreferBinarySerialization，因为 YAML 表示效率较低。一个 10000 元素的 float[] 在 YAML 中可能比二进制大 5-10 倍。

God Object ScriptableObject

把所有游戏配置塞进一个巨大的 ScriptableObject 是常见反模式——修改任何参数都需要重新序列化整个资产，且不同系统产生不必要的耦合。应按职责拆分：CombatConfig、MovementConfig、AudioConfig 各自独立。

运行时修改 SO 后的隐式副作用

退出 Play Mode 时，Editor 会还原 ScriptableObject 的序列化状态——但在 Play Mode 期间，所有引用者看到的是被修改后的值。如果测试逻辑依赖默认值，可能产生”Play Mode 中正常但构建后不对”的问题。在 OnEnable 中重置非序列化状态是安全做法。

ScriptableObject 循环引用

ScriptableObject A 引用 B，B 又引用 A（或间接循环）。Unity 序列化系统能处理循环引用，但会导致序列化/反序列化性能下降，且 Inspector 中显示可能异常。设计上应避免循环依赖。

在 SO 中存储运行时状态

ScriptableObject 的设计意图是”共享配置数据”。如果把运行时状态（当前血量、存活数量）放在 SO 中，所有实例共享同一状态，通常不是你想要的。运行时状态应放在 MonoBehaviour 或 ECS ComponentData 中。
